## 一元二次方程高精度计算

命令行精确求解 `ax² + bx + c = 0`。支持有理数输入，进行高精度计算。

### 设计目的

我们都知道~~并非~~，如果计算机要表示小数，也是通过二进制来表示：比如 `0.1011`，即 `2^-1 + 2^-3 + 2^-4 = 0.6875`。

据此可知，就和十进制无法精确表示部分无限循环小数一样，二进制的精度会更差，同时当前大部分计算机还有 64 位的限制，即能直接表示的最大整数为 `2^64 - 1 = 184467440737095516165`。

现在如果想让计算机进行和十进制一样精度的计算、或者突破 64 位的限制，就必须使用多个 bit 来表示一位十进制数位，专业的计算工具一般使用半个字节来表示一位，本人能力有限，还是一个字节表示一位为好。

这次的作业过于简单，加点难度，一元二次方程就用高精度解决。听起来很复杂，但其实也就是竞赛中高精度计算部分，只不过要考虑分数的与根号的处理。此处不用在乎复杂度、性能之类的东西，所以按照认知的基本常识去模拟分数或根号计算就行了。

### 输入方式

CLI 界面类似：

```text
[MATH] _x^2+_x+_=0 > 1 0 -8
Equation: x^2 - 8 = 0
Delta = 32
x1 = 2sqrt(2)
x2 = -2sqrt(2)
```

即 `a b c` 三个系数，对应 `ax² + bx + c = 0`。每个数都可以写成：

| 写法 | 含义 |
| --- | --- |
| `2`、`-5` | 整数（任意长度） |
| `1.25`、`-0.5` | 小数，先转成 `125/100` 再约分成 `5/4`，不存在二进制浮点误差 |
| `3/7`、`-18/24` | 分数，自动约分成 `3/7`、`-3/4` |

### 两种模式

两种模式的差别是**输出的每个数**用哪种形式表示：
MATH 一律给数学形式，
SCI 一律给科学形式。

**MATH**：

```text
1 2 1    →  Delta = 0     x1 = x2 = -1
1 -5 6   →  Delta = 1     x1 = 3                x2 = 2
1 0 -2   →  Delta = 8     x1 = sqrt(2)          x2 = -sqrt(2)
1 -1 -1  →  Delta = 5     x1 = (1 + sqrt(5))/2  x2 = (1 - sqrt(5))/2
3 -7 2   →  Delta = 25    x1 = 2                x2 = 1/3
```

**SCI**：

```text
3.7 2 6/7  →  > 37/10x^2 + 2x + 6/7 = 0          （MATH）
              Equation: 3.7x^2 + 2x + 0.85714285714285714285714285714285714 = 0
              Delta = -8.68571428571428571428571428571428571
              No real roots

1 0 -2     →  x1 = 1.41421356237309504880168872420969808
              x2 = -1.41421356237309504880168872420969808
```

能除尽的有理数直接输出精确值，不补零。

回显的方程按数学写法给符号：负系数写成减号。

`a = 0` 时输出 `Error: Nonquadratic`；
`D < 0` 时输出 `No real roots`；
`D = 0` 时输出 `x1 = x2 = ...`。

### 核心设计

#### 大整数：一位一字节

```cpp
struct Big {
    bool neg = false;              // 符号
    std::vector<unsigned char> d;  // d[0] 是个位，每个元素保存一位数字 0~9
};
```

`unsigned char` 能存 `0~255`，保存一位十进制数字（`0~9`）绰绰有余。例如 `583920` 内部是 `{0,2,9,3,8,5}`，小端存放使进位方向与手算一致：

```cpp
int v = a.d[i] + b.d[i] + carry;   // 用 int 只做单位临时量，不进位就不会溢出
a.d[i] = v % 10;  carry = v / 10;
```

减法借位、乘法竖式、除法长除（每位最多减 9 次）、欧几里得求 `gcd` 都建立在它之上。
`vector` 可以动态扩展，因此没有位数上限；复杂度为加减 `O(n)`、乘除 `O(n²)`。

#### 有理数

```cpp
struct Rat {
  Big p, q;
};
// 分子 / 分母，每次运算后约分，负号归到分子
```

输入 `0.125` 不会写进 `double`，而是变成 `125/1000` 再约分成 `1/8`；`18/24` 约分成 `3/4`。
判别式 `D = b² - 4ac` 因此在有理数域内精确计算，不会被浮点误差改变符号。

#### 求根与根式化简

记 `D = P/Q`（最简），则 `√D = √(P·Q)/Q = s√r/Q`，其中 `P·Q = s²r` 且 `r` 无平方因子。
代回求根公式并通分，两个根可统一写成

```text
x = (A ± B√r) / C
```

再对 `(A, B, C)` 提取公因子即得最简形式，例如 `√8` 化简为 `2sqrt(2)`、`√(1/4)` 直接得到 `1/2`、`(0 ± 2√2)/2` 化成 `±sqrt(2)`。`r = 1` 时根式消失，退化为普通分数。

#### 高精度十进制

`√r` 用整数平方根（牛顿迭代 `x ← (x + n/x)/2`，初值取上界保证单调下降）在放大 `10^k` 倍的整数上求，再与 `A/C` 合并做长除法逐位求小数，全程只用到整数运算。多算若干保护位以抵消 `√r` 的截断误差，最后一位四舍五入，因此 `√2` 能得到与规范一致的 `1.41421356237309504880168872420969808`。
