### 18. 此处为什么要将str初始化为NULL，否则会发生什么情况？
- 因为在 `GetHeapString(char*& str, const char* source)`中：
```cpp
if (str == NULL)
{
    str = new char[1];

}
```
如果不 `NULL`，`str` 就不会分配到内存。

### 21. 请分别画出strA，strB，strC，strD，strE的结构图，指出它们所在的空间（常量池、栈区、堆区）
- `strA`：
栈区二维数组。
字符串内容直接存放在栈上的二维数组中。

- `strB`：
栈区有一个指针数组，每个指针指向常量池中的字符串字面量。
指针本身在栈区，字符串内容在常量池。

- `strC`：
变量在栈区，指向堆区的指针数组。
堆区指针数组的每个元素又指向堆区单独分配的字符串副本。

- `strD`：
变量在栈区，指向堆区的指针数组。
每个元素通常指向堆区可修改的字符串副本。

- `strE`：
变量在栈区，指向堆区的指针数组。
每个元素指向常量池中的字符串。
### 22. 此处为什么不能用BubbleB函数？
- `char**` 与 `char (*)[]` 并非相同类型。
### 23. 为什么 strB 不能用 BubbleA？编译能过但运行出错？
- `strB` 是常量。
### 24. 为什么 strC 能用 BubbleB？strC[0] 是否被改变？
- `strC` 是 `char**`，且每个元素指向堆区可修改字符串；会。
### 25. 释放 strC 时，为什么第三个参数不能采用默认值 false？
- 因为 `GetStrings0` 为 `strC` 的每个字符串都单独分配了堆内存。
### 26. 为什么这里要用 BubbleA？strC[0] 是否被改变？内容是否被改变？
- 因为 `strC` 的每个元素指向堆区可写字符串，所以可以用 `BubbleA` 直接交换字符串内容；会改变。
### 27. 为什么 strD 既可以用 BubbleA，又可以用 BubbleB？
- 因为 `strD` 是 `char**`，并且它指向的字符串内容是可写的。
### 28. 此处为什么不能用BubbleA函数？
- `strE` 指向常量池中的字符串，`BubbleA` 会写入字符串内容，导致运行时错误，所以不能用。
### 29. 是否可以写成 FreeStrings(strE, n0, false);？
- 可以。
### 30. 是否可以写成 FreeStrings(strC, 1);？
- 不可以。
